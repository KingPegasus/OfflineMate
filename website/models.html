On-device AI models for Android

OfflineMate runs quantized language models on your phone instead of in the cloud. Here’s every model it offers, how large each download is, and how much RAM each tier targets.

How to choose a model

Start with your phone’s RAM, because the model has to fit in memory alongside Android and your other apps. Pick the tier that matches, then use its default model. It’s the option OfflineMate suggests for that tier.

A larger model generally gives better answers, but it takes more storage and memory. If a model fails to load, the app can fall back to a lighter tier.

What the sizes mean

The sizes above are estimates for the chat model file alone. Setup also downloads speech and search files, so the total is higher: about 210–560 MB for Lite, and about 1.2 GB for Standard and 2.2 GB for Full with their default models.

The “135M” or “4B” in a model’s name is its parameter count, in millions or billions. These builds are quantized, which shrinks them enough to run on a phone.

OfflineMate downloads these models from Hugging Face. Select a model name in the tables above to see its source page.
